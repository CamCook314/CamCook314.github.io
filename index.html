Parallel Matrix Decomposition

Householder / Hessenberg reduction · C, OpenMP · University, COSC3500

Implemented Householder-transform matrix reduction from scratch on arbitrary N×N matrices, using no numerical libraries. Parallelised with OpenMP, then profiled and cache-optimised across successive versions to a measured >100× improvement over the first working implementation. Built with a Makefile, run as SLURM-scheduled batch jobs on a Linux cluster, with output validated against reference results.

Searchable Archive Pipeline

Document processing & search · Python, JavaScript · pro bono client project

A batch pipeline converting scanned photographs and PDFs into a full-text-searchable corpus for a non-technical end user, paired with a hand-built, zero-dependency search engine — inverted index, TF-IDF-style ranking, fuzzy and wildcard matching.

Two findings mattered more than the build: a shared-engine concurrency bug that only surfaced under load (~6× throughput once fixed), and a scoring metric quietly rewarding the wrong signal rather than genuine matches. Neither presented as an obvious failure; both needed working backwards from behaviour to cause.

Critical Minerals World Map

Geospatial data visualisation · D3.js · commissioned, not yet public

An interactive world map linked bidirectionally to a periodic table, so official critical-minerals-by-country designations can be explored from either direction — click a country to light its minerals, or an element to light its producers. Multi-select filtering resolves to the intersection rather than the union.

Backed by a spreadsheet-to-JSON data pipeline and a single-file standalone build, so the whole tool ships as one self-contained HTML artefact with no hosting dependency.
